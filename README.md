## Setup and Run

1. **Enter the development environment:**
   ```bash
   devenv shell
   ```

2. **Build the project:**
   ```bash
   mvn clean install
   ```

3. **Run the application:**
   ```bash
   mvn spring-boot:run
   ```

4. **Access:**
   - [http://localhost:8080](http://localhost:8080)
